匹克球的球看起來都差不多，都是有洞的塑膠球，但比賽用的球有一套規格，還要列在 USA Pickleball 的核可清單上。平常打球不用太講究，**要比賽，或想買一盒自己練，才需要分清楚**。

室內球和戶外球差在哪，[第一次打匹克球](/articles/first-time-pickleball/)那篇已經講過。這篇講比賽用球：規格是什麼、比賽怎麼指定、清單怎麼查，以及在台灣去哪裡買。

## 先看結論：什麼情況買什麼球

| 你的情況 | 怎麼選 |
|---|---|
| 去臨打 | 現場通常有球，跟大家用一樣的就好 |
| 買一盒自己練 | 選核可清單上查得到的球，看你常打的場地用室內還是戶外球 |
| 準備報名比賽 | 看簡章的「指定用球」，買同一款來練 |
| 只想便宜練習 | 沒核可的球也能打，只是手感可能和比賽用球不一樣 |

## 一顆比賽用球長什麼樣

USA Pickleball 的器材標準手冊，對比賽用球的大小、重量、彈跳和洞數都有規定：

<BallSpec />

| 項目 | 規定 |
|---|---|
| 直徑 | 7.29 到 7.54 公分 |
| 重量 | 22.1 到 26.5 公克 |
| 彈跳 | 在攝氏 21 度上下 3 度的室溫下，從 198 公分高落到花崗岩平台，球頂要彈到約 76 到 86 公分 |
| 洞 | 26 到 40 個圓洞 |
| 外觀 | 表面光滑、沒有紋路；除了標誌和文字，整顆同一個顏色，顏色不限 |
| 標示 | 球上要印或壓上製造商或供應商的名字或標誌 |

手冊還有壓縮測試，以前也量硬度，但硬度現在只記錄、不再當合格標準。

規則書也寫明，**所有核可的球，室內戶外都能用**。室內球洞少、戶外球洞多，是習慣上的分法，不是規則；核可清單也會標室內或戶外，但不限制在哪裡用。

## 比賽用哪一顆球

比賽的球由主辦單位決定。USA Pickleball 的規則是：**賽事主辦人從核可清單裡挑一款球當比賽用球**。

台灣的比賽不一定照 USA Pickleball 規則辦：中華民國匹克球總會的比賽採 GPF（全球匹克球總會）規則，臺中國際公開賽則採 USA Pickleball 規則。所以比賽前要看的是簡章，簡章會寫「大會指定用球」或「比賽用球」，例如：

| 比賽 | 簡章寫的指定用球 | 在核可清單上嗎 |
|---|---|---|
| 中華民國匹克球總會 2026 年的臺北公開賽、港都盃、中正盃 | DUOPRO | 有。簡章沒寫型號，清單上 DUOPRO 名下只有 1.0 一款 |
| 2026 臺中國際匹克球公開賽 | JOOLA HC-40 | 有 |

兩邊指定的球都在核可清單上，但不同主辦單位用的球不一樣。報名前先看清楚，**用同一款球練**，上場才不會覺得球突然變快、變彈。

比賽怎麼報名、等級怎麼分，之後會另外寫一篇整理。

## 核可清單怎麼查

USA Pickleball 的[核可球清單](https://equipment.usapickleball.org/ball-list/)把所有通過測試的球列成一張表，目前約四百列。每一列有四個欄位：

| 欄位 | 意思 |
|---|---|
| Brand | 登記的品牌 |
| Model | 型號，同一款不同顏色常會分開列 |
| Ball Type | Ind、Out、I/O 三種，清單沒有解釋，字面上是室內（Indoor）、戶外（Outdoor）和室內外兩用；有些列空白 |
| List Date | 列進清單的日期，有些列空白 |

查的時候有兩件事要注意：

- **商品頁寫「USAPA 認證」不算數**。以清單查得到為準。台灣賣場的商品名常寫「美國 USAPA 認證」，清單上卻不一定找得到對應的型號。
- **賣場上的品牌名，不一定是清單上的名字**。迪卡儂台灣賣場的球掛 KUIKMA 品牌，清單上沒有 KUIKMA，但有幾款球登記在 DECATHLON 名下。台灣的商品頁沒寫對應哪一款，所以沒辦法確認是同一顆。查不到時，可以換母公司名稱或型號再搜一次。

幾個觀察：

- **我們查到的幾乎都是戶外球**，迪卡儂的台灣網站沒找到室內球。規則上戶外球在室內也能用，只是手感比較硬。

## 球裂了怎麼辦

塑膠球打久了會裂、會變軟。球在一分當中裂開，規則是這樣處理的：

1. **先把這一分打完**，不能打到一半停下來。
2. 打完之後，**大家都同意**就換球。
3. 如果大家都同意，是裂掉的球影響了這一分的結果，**這一分重打**；沒有共識，這一分照算。

球只是變軟、還沒裂，這一分照算，不重打；要換球也要所有球員同意。

有裁判的比賽，球員可以請裁判判斷：裁判認定球裂了就換球，認定影響了結果就用新球重打。

## 常見問題

<details>
<summary>室內球可以拿到戶外打嗎？</summary>

規則上可以，核可的球室內戶外都能用。只是室內球比較輕、比較軟，戶外有風時比較容易飄。兩種球的差別見[第一次打匹克球](/articles/first-time-pickleball/)。
</details>

<details>
<summary>練習可以用沒核可的便宜球嗎？</summary>

可以。核可清單管的是能不能用在 USA Pickleball 認可的比賽，平常打球用什麼球由你和球友決定。USA Pickleball 的器材手冊也強烈建議，休閒用的器材在製造時一樣符合這些規格。準備比賽的話，最好換成比賽指定的那一款球練。
</details>

<details>
<summary>匹克球一定是黃色的嗎？</summary>

不一定。規則只要求整顆同一個顏色，顏色不限，所以清單上有黃、綠、橘、粉紅、紫等各種顏色。規則書也提醒，衣服不要穿跟球顏色太接近的；比賽中，主辦人可以要求你換掉。
</details>
