匹克球的球看起來都差不多，都是有洞的塑膠球，但比賽用的球有一套規格，還要列在 USA Pickleball 的核可清單上。平常打球不用太講究，**要比賽，或想買一盒自己練，才需要分清楚**。

室內球和戶外球差在哪，[第一次打匹克球](/articles/first-time-pickleball/)那篇已經講過。這篇講比賽用球：規格是什麼、比賽怎麼指定、清單怎麼查，以及在台灣去哪裡買。

## 先看結論：什麼情況買什麼球

| 你的情況 | 怎麼選 |
|---|---|
| 去臨打 | 現場通常有球，跟大家用一樣的就好 |
| 買一盒自己練 | 選核可清單上查得到的球，看你常打的場地用室內還是戶外球 |
| 準備報名比賽 | 看簡章的「指定用球」，買同一款來練 |
| 只想便宜練習 | 沒核可的球也能打，只是手感可能和比賽用球不一樣 |

## 一顆比賽用球長什麼樣

USA Pickleball 的器材標準手冊，對比賽用球的大小、重量、彈跳和洞數都有規定：

<BallSpec />

| 項目 | 規定 |
|---|---|
| 直徑 | 7.29 到 7.54 公分 |
| 重量 | 22.1 到 26.5 公克 |
| 彈跳 | 在約攝氏 21 度的室溫下，從 198 公分高落到花崗岩平台，要彈到 76 到 86 公分 |
| 洞 | 26 到 40 個圓洞 |
| 外觀 | 表面光滑、沒有紋路，整顆同一個顏色，顏色不限 |
| 標示 | 球上要印或壓上製造商的名字或標誌 |

手冊還有壓縮測試，以前也量硬度，但硬度現在只記錄、不再當合格標準。

規則書也寫明，**所有核可的球，室內戶外都能用**。室內球洞少、戶外球洞多，是廠商和球友習慣的分法，不是規則。

## 比賽用哪一顆球

正式比賽的球由主辦單位決定。USA Pickleball 的規則是：**賽事主辦人從核可清單裡挑一款球當比賽用球**。

所以比賽前要看的是簡章。台灣的比賽簡章會寫「大會指定用球」或「比賽用球」，例如：

| 比賽 | 簡章寫的指定用球 | 在核可清單上嗎 |
|---|---|---|
| 中華民國匹克球總會 2026 年的臺北公開賽、港都盃、中正盃 | DUOPRO | 有，DUOPRO 1.0 |
| 2026 臺中國際匹克球公開賽 | JOOLA HC-40 | 有 |

不同主辦單位用的球不一樣。報名前先看清楚，**用同一款球練**，上場才不會覺得球突然變快、變彈。

比賽怎麼報名、等級怎麼分，之後會另外寫一篇整理。

## 核可清單怎麼查

USA Pickleball 的[核可球清單](https://equipment.usapickleball.org/ball-list/)把所有通過測試的球列成一張表，目前大約四百款。每一列有四個欄位：

| 欄位 | 意思 |
|---|---|
| Brand | 登記的品牌 |
| Model | 型號，同一款不同顏色常會分開列 |
| Ball Type | Ind、Out、I/O 三種，清單沒有解釋，字面上是室內（Indoor）、戶外（Outdoor）和室內外兩用；有些列空白 |
| List Date | 列進清單的日期，有些列空白 |

查的時候有兩件事要注意：

- **商品頁寫「USAPA 認證」不算數**。以清單查得到為準。台灣賣場的商品名常寫「美國 USAPA 認證」，清單上卻不一定找得到對應的型號。
- **賣場上的品牌名，不一定是清單上的名字**。迪卡儂的球在台灣賣場掛 KUIKMA 品牌，清單上卻找不到 KUIKMA；迪卡儂的球登記在 DECATHLON 名下，有幾款戶外球和一款室內球。查不到時，換母公司名稱或型號再搜一次。

球拍也是一樣的查法，例子見[匹克球拍推薦](/articles/paddle-recommendations/)最後一段。

## 台灣買得到哪些球

我們查了品牌官網和大型通路，下面是目前找得到、而且看得出是誰在賣的球。網拍上的個人賣家沒有列入。

| 球 | 哪裡買、價格 | 核可清單 |
|---|---|---|
| KUIKMA 戶外匹克球 | 迪卡儂，3 顆 199 元、12 顆 749 元 | 清單上沒有 KUIKMA；DECATHLON 名下有戶外球，但商品頁沒寫對應哪一款 |
| BLAZESTAR 匹克球 PRO | 迪卡儂，3 顆 299 元、12 顆 999 元 | 清單上有 BLAZESTAR PRO-X4，商品頁沒寫型號，對不上是不是同一款 |
| ARTENGO 室外匹克球 | 迪卡儂，1 顆 69 元 | 商品頁寫法國、比利時球員測試過，沒提 USA Pickleball，適合練習 |
| Franklin X-40 | 迪卡儂合作廠商出貨，1 顆 119 元 | 有 |
| INFMARC TW-40 | 迪卡儂合作廠商出貨，3 顆 180 元 | 有 |
| KASACA 比賽級 40 孔室外球 | 迪卡儂合作廠商出貨，3 顆 210 元起 | 查不到，商品頁也沒寫核可 |
| JOOLA Primo | JOOLA 台灣官網，4 顆一組，價格以官網或官方蝦皮商城為準 | 有 |
| Selkirk Q1 Quiet Ball | Selkirk 亞洲官網跨境寄送，3 顆起，網站換算台幣，可能另有關稅 | 有，標室內外兩用 |

幾個觀察：

- **台灣通路賣的幾乎都是戶外球**。迪卡儂的台灣網站沒找到室內球。規則上戶外球在室內也能用，只是手感比較硬、比較快。
- 「合作廠商出貨」是迪卡儂網站上的運動商城合作夥伴商品，由其他公司出貨，不是迪卡儂自己的庫存，退換貨要看合作廠商的規定。
- Franklin、Onix、HEAD 這幾個美國常見的品牌，我們沒找到台灣的官方代理或品牌直營通路。
- 換算下來，一顆大約 60 到 120 元。核可的球不一定比較貴，便宜的練習球也不一定不能用。

## 球裂了怎麼辦

塑膠球打久了會裂、會變軟。球在一分當中裂開，規則是這樣處理的：

1. **先把這一分打完**，不能打到一半停下來。
2. 打完之後，**大家都同意**就換球。
3. 如果大家都同意，是裂掉的球影響了這一分的結果，**這一分重打**。

有裁判的比賽，改由裁判判斷球是不是裂了；裁判認定裂了就換球，認定影響了結果就用新球重打。球只是變軟、還沒裂，要所有球員都同意才換。

平常打球，看到球有裂痕就換掉。裂開的球彈跳會變得不規則，打起來也不準。

## 常見問題

<details>
<summary>室內球可以拿到戶外打嗎？</summary>

規則上可以，核可的球室內戶外都能用。只是室內球比較輕、比較軟，戶外有風時比較容易飄。兩種球的差別見[第一次打匹克球](/articles/first-time-pickleball/)。
</details>

<details>
<summary>練習可以用沒核可的便宜球嗎？</summary>

可以。核可清單管的是能不能用在 USA Pickleball 認可的比賽，平常打球用什麼球由你和球友決定。USA Pickleball 的器材手冊也說，它強烈建議休閒用的器材一樣符合這些規格。準備比賽的話，最好換成比賽指定的那一款球練。
</details>

<details>
<summary>匹克球一定是黃色的嗎？</summary>

不一定。規則只要求整顆同一個顏色，顏色不限，所以清單上有黃、綠、橘、粉紅、紫等各種顏色。規則書也建議，衣服不要穿跟球顏色太接近的。
</details>
