## 刻意不寫

- 費用：原則不列價格（網球中心每小時 400／800 元、學校球聚 NT$150～350 都不寫）。
- 商業球館：原則不列（總會 API 台北有十多家）。
- 總會 API 裡標「PickleTown 使用者提供，未經總會實地確認」的 24 筆（伊通公園、民族公園、彩虹河濱等）：沒有官方確認，不寫。
- 天母公園、道南河濱共用場：總會 API 引用體育局，但體育局場地頁抓不到內容，未能自己確認，先不寫。
- 總會 API 寫華中河濱「全天開放」、捷運綠帶「08:00–22:00」，跟體育局場地頁（08:00–17:00、09:00–18:00）不同，以體育局為準。
- 公館水源新天地是「虛擬匹克球」，不是實體球場。
- 運動中心的匹克球時段：協會清單有寫，但運動中心官網沒有匹克球頁，時段變動大，不寫。
