- H2：
  1. 為什麼不能只打幾個 dink（圖：WarmupSteps）
  2. 第一步：讓心跳上來
  3. 第二步：動態伸展，從上到下（表）
  4. 第三步：每一種球都熱過（表＋StepBackDrill）
  5. 一次只想一件事
- 往內連：練習篇「上場前先熱身」加連結
