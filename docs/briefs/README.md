# 選題清單

流程見 [`../ARTICLE_WORKFLOW.md`](../ARTICLE_WORKFLOW.md)（最前面有開工清單）。每個題目一張選題卡，範本是 `_TEMPLATE.md`。

**每個題目現在的狀態不看這份**，跑 `npm run topics:status`：它會讀 main 和每個 `claude/*` 分支上的選題卡「狀態」欄，列出誰在寫什麼。認領題目就是改自己那張卡的狀態再 push。這份 README 只記每一輪選題的資料和排序，各討論串不要改它，免得分支互相衝突。

## 2026-11-15 第一輪

**資料**：在站主電腦跑 `scripts/topics/suggest.py`，9 個種子詞（匹克球、匹克球拍、匹克球 規則／新手／發球／技巧／場地／計分、pickleball），共 171 次查詢，得到 304 個不重複建議詞。原始 TSV 在萃取端 `output\topics\suggest-2026-11-15.tsv`。

**雜訊**（已濾掉）：
- 香港用語，例如開波、荃灣、荔枝角、廣東話。
- 簡體重複詞。
- 台中某球館的地圖條目。

**限制**：自動完成只代表「有人這樣搜」，不代表搜尋量。網站有 Search Console 數據後要回頭校正排序。
