## 大綱

- 標題：匹克球 dink 怎麼打：步法、落點、何時 speed up
- 開頭要先回答：dink 是高低的遊戲，目標是讓對手由下往上打；不是打大力，是放到腳邊
- H2：
  1. dink 在比什麼：高低、腳邊、每一拍都在鋪路
  2. push dink 照四個順序學：握拍 → 步法 → 擊球點 → 揮拍（圖：擊球點）
  3. 球落在腳邊時：截擊 dink 或後撤一步（表）
  4. 打去哪：外側腳、內側腳、中間（圖：落點）
  5. 什麼時候可以 speed up（圖：三個檢查）
  6. 失去平衡時：放軟、放慢、打中間
  7. roll dink 與 dink 練習
