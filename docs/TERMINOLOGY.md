# 用語表

站主原則（2026-11-14）：用台灣球友的說法；台灣習慣直接講英文的詞，就用英文。

依據（2026-11 查）：台灣學校課程講義、台灣教練部落格 PiCoach、經理人、vocus 文章。來源少，之後用 GSC 實際搜尋字詞修正。
