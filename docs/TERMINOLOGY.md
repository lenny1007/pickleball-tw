## 長度單位（站主 2026-11-19 定）
台灣讀者多半沒辦法自動換算英尺，讀者看得到的長度一律用公制。

| 情況 | 寫法 | 例 |
|---|---|---|
| 教練建議的距離、高度（本來就是概數） | 只寫公制概數，不留英制 | 過網約 90 公分、離底線約 1.2 公尺 |
| 官方規格（場地、網高、球拍上限） | 公制在前，英制放括號 | 2.13 公尺（7 英尺） |
| 握把周長、長度 | 公制在前，英制放括號（店家規格標英寸） | 約 10.8 公分（4.25 英寸） |

- 英制只寫「英尺」「英寸」，不寫「呎」「吋」。
- 圖解的標示、說明文字、aria-label 同樣照這張表。程式註解不限。
- 影片用英尺的文章，文末「這篇怎麼整理的」寫「影片用英尺，內文換算成公制概數」。
