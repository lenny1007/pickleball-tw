新手最常卡住的規則

第一次上場前看完這幾條，跟陌生球友打臨打就不會一直被糾正。

  • 非截擊區（廚房區）是什麼？

    網子兩側各 2.13 公尺（7 呎）的區域。站在裡面不能截擊，也就是球沒落地前不能打。

  • 雙彈跳規則

    發球後，接發方要等球彈地一次再打，發球方回擊時也要等彈地一次。之後才可以截擊。

  • 發球一定要低手嗎？

    傳統發球要低手、擊球點在腰部以下，往對角發。另有「落地發球」可以先讓球落地再打。

  • 分數怎麼算？

    一般打到 11 分、領先 2 分獲勝；傳統計分只有發球方能得分，雙打報分會報三個數字。
